# ⚽ Futbol 5 App

A simple and intuitive web application to organize and manage small-sided football matches (5v5 or 6v6).

## 🚀 Features

* Create and manage matches
* Add and remove players
* Organize teams easily
* Clean and responsive UI
* Built with modern frontend technologies

## 🛠️ Tech Stack

* React
* TypeScript
* Vite
* CSS

## 📦 Installation

Clone the repository:

```bash
git clone https://github.com/agustinstaiger9/futbol5-app.git
```

Navigate to the project folder:

```bash
cd futbol5-app
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```
